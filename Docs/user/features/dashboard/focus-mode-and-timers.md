# Focus Mode and Timers

Focus mode is the part of FlowState that helps you turn a vague intention to work into a visible, time-bounded session. It is especially useful when you already know what task matters and you want help staying on it.

## What focus mode is for

Focus mode helps with:

- deliberate work sessions
- timer-based work rhythms
- pomodoro-style cycles
- reducing aimless tab switching

It is not meant to replace planning, boards, or messaging. It works best after those other systems have already helped you choose what matters.

## What a focus session is

A focus session is a block of time with a purpose.

Instead of:

- vaguely “working for a while”

you decide:

- what you are working on
- how long you want to focus
- what the session will count as success

This makes progress easier to measure and interruptions easier to reason about.

## Why timers help

Timers are useful because they create boundaries.

They help answer:

- when did I start
- when should I reassess
- how long did I actually spend focusing

That is often more useful than trying to “feel productive” without structure.

## Pomodoro-style usage

One common pattern is:

1. choose one task
2. set a focused work interval
3. work until the timer ends
4. pause briefly
5. either repeat or switch context intentionally

This is useful when a task is meaningful but not exciting, because the timer creates a manageable commitment.

## Choosing the right task

Focus mode works best when the chosen task is:

- specific
- meaningful
- possible within one session

Good examples:

- review one list of cards
- answer a set of important replies
- write one draft
- clean up one board area

Bad examples:

- fix everything
- catch up on my whole job
- maybe explore and see what happens

## When not to use focus mode

Focus mode is not always the right tool.

It is less helpful when:

- you are waiting for urgent back-and-forth conversation
- your work is highly reactive
- you need to coordinate actively in real time
- the task is still too vague

In those cases, a dashboard review, thread conversation, or board planning step may need to happen first.

## Combining focus mode with the rest of FlowState

A helpful pattern is:

1. check dashboard
2. choose a task from a board or thread
3. start a focus session
4. complete the session
5. return to the board or conversation and update the result

This turns focus mode into part of a work loop instead of an isolated gadget.

## Common mistakes

### Starting a timer without choosing a real task

The timer then measures drift instead of progress.

### Using the timer as guilt

Focus mode should create structure, not shame.

### Ignoring new urgent reality

If something truly urgent changes, stop and handle it. The timer is a tool, not a prison.

### Never closing the loop

If you finish a session but never update the board, message, or task, your teammates still do not know what changed.

## Beginner-friendly workflow

If you are new to timers:

1. choose one small real task
2. start one modest session
3. finish it
4. write one update or move one card afterward

That is enough to make focus mode useful without overcomplicating it.
