# I Want to Onboard a New Person Into the Workspace

This tutorial is mainly for admins or trusted workspace managers.

## Goal

You want to:

- invite someone safely
- assign the right access
- help them succeed from day one

## Suggested onboarding flow

1. confirm they should have access
2. create the invite
3. share the invite link carefully
4. monitor whether it is accepted, expired, or revoked
5. verify their role assignment
6. confirm they can access the exact board or channel they need
7. point them to the dashboard and the right docs

## Important caution

Do not solve every onboarding case by over-granting permissions. Use the right role first and overrides only when needed.
