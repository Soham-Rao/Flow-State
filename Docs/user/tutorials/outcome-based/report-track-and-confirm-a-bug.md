# I Want to Report, Track, and Confirm a Bug

This tutorial is for users who want to send a good bug report and understand what happens next.

## Goal

You want to:

- describe the issue clearly
- make sure it reaches the team
- check whether it was reviewed

## Suggested reporting flow

1. reproduce the issue once carefully
2. note the page and action involved
3. open Advanced settings
4. write a useful title
5. explain what happened and what you expected
6. submit the report
7. review your recent reports and watch the status

## Status meaning

- `open`: received
- `triaged`: reviewed and categorized
- `closed`: the issue’s report lifecycle is complete
