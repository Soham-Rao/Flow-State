# I Want to Run a Project From Idea to Done

This tutorial is for turning FlowState into the main operating space for a project.

## Goal

You want to:

- organize work
- coordinate people
- track progress visibly
- finish cleanly

## Suggested project flow

1. create or choose the correct board
2. define a sensible list structure
3. create the first set of cards with real titles and ownership
4. use comments and threads for coordination, not for replacing planning
5. move cards as status changes
6. use announcements if a broad audience needs visibility
7. archive completed work that no longer needs active attention

## Key rule

Do not let the board become a decorative planning artifact. Keep it close to reality or it stops being trustworthy.
