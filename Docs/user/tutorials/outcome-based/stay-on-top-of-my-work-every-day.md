# I Want to Stay on Top of My Work Every Day

This tutorial is for using FlowState as a daily coordination system rather than opening it only when forced.

## Goal

You want to:

- know what changed
- know what needs your attention
- move one thing forward at a time
- avoid dropping work

## Suggested daily loop

1. sign in and start on the dashboard
2. scan announcements, mentions, and assigned cards
3. choose one important board or thread to open first
4. update the work honestly
5. reply where needed
6. use focus mode if the next task is clear
7. return later to the dashboard for reorientation

## Why this works

This keeps you from:

- bouncing randomly between pages
- forgetting follow-up
- confusing conversation with tracked work

The dashboard tells you where to look. Boards and threads are where you act.
