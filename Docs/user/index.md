## What FlowState is

FlowState is a team workspace that combines several kinds of work in one place:

- planning and tracking work with boards, lists, cards, labels, due dates, and assignments
- discussing work through board comments and thread-based messaging
- coordinating in direct messages and shared channels
- keeping up with mentions, announcements, activity, and assigned work from a dashboard
- managing focus sessions with a built-in timer
- handling roles, permissions, overrides, and administrative controls for shared collaboration

## Important note

FlowState is a web app. That means:

- you usually use it through a browser
- you do not install a traditional desktop program to access it
- the website itself is the product
- your browser shows the interface, but most permanent data is stored on the server

If you have ever wondered, “What exactly am I using when I open the site?”, the short answer is:

- the browser shows the visual interface
- the site talks to the FlowState server in the background
- the server loads and saves the real data for your team

This documentation focuses on what you, as a user, need to do with confidence.
